Part C: Explore

If you temporarily remove the $(document).ready() wrapper from the header of your document:

1. Does the page still work as expected? No,the buttons no longer have a function. If the script is in the header without $(document).ready(), clicking the buttons will do nothing.

2. Does the location of the script affect the result? Yes, if you remove $(document).ready() but move the entire script to the very bottom of the page the code will work. This is because the browser reads top-to-bottom; by the time it reaches the script at the bottom, the paragraphs and buttons have already been loaded into the DOM.

3. Why is $(document).ready() useful? It guarantees that your jQuery code will not run until the DOM is completely loaded and safe to manipulate. This prevents undefined element errors and allows you to keep your scripts neatly organized in the header of your HTML document without worrying about whether the elements have loaded yet.
